# Compatibility Notes

Preserve these identifiers exactly:

- `window-loom-theme`
- `window-loom-editor-layout`
- `window-loom-editor-shortcuts`
- `application/x-window-loom-timeline`
- `VIDEO_TOOL_*`
- `window.videoTool`
- `local_qwen`

These names can appear in docs as compatibility details. Don't title the product with the old brand when writing user-facing docs.
